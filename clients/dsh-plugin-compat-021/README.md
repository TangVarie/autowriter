# 写作台插件 · DeepSeek Harness 0.2.1 兼容版

**只给 Intel 芯片的 Mac 用。** DeepSeek Harness 的 Intel 桌面版停在 0.2.1（更新通道 10 月 27 日之后没再动过），正常版插件（`clients/dsh-plugin`）要 0.2.2 起，装不上。这一份是正常版的一个单独分支，让它在 0.2.1 上能跑。

> **验证到哪一步**：照 DSH 0.2.1-rc.1 和 0.2.1-rc.4 的源码逐项核对过插件用到的每个接口，单元测试覆盖了改动的部分（包括照 DSH 自己的求值方式跑预设里的表达式）。**没有在真实的 0.2.1 桌面端上跑过**，第一次装请由负责人在 Intel Mac 上走一遍。

## 和正常版的区别（只有这些）

| 地方 | 正常版 | 兼容版 | 为什么 |
|---|---|---|---|
| `package.json` 的 `engines.dsh` | `>=0.2.2-rc.1` | `>=0.2.1-rc.1` | 0.2.1 的插件管理器按它拦安装 |
| 预设里连写作台的那一行：地址和钥匙从哪来 | MCP 客户端自己用 `${credential:…}` 模板去凭据库取 | 宿主插件挂一个读凭据文件的函数（`lib/credfile.js`），预设里用 `!!js` 调它 | 0.2.1 的 MCP 客户端不认模板 |
| 配完 `/desk-setup` 之后 | 新开一个对话就行 | **要完全退出 DSH 再打开一次** | 上一条的代价：预设激活时才读一次 |
| 预设里的 Office 工具 | 有 | 没有 | 0.2.1 里没有这个包，列上会让整个预设起不来 |
| 认「这个对话是不是写作台对话」 | `presetForSession`、`definitions` | 先试这两个，没有就退到 `composedPreset`、`schemas` | 0.2.1 里只有后两个 |

钥匙不写进包里：和正常版一样，每位写手用 `/desk-setup` 填自己的那把，存在桌面端自己的凭据库（`~/.dsh/.credentials.yaml`）。

## 写手怎么装

1. 装好 Intel 版 DeepSeek Harness，登录。
2. 侧栏「插件」→「添加插件」→「安装第三方插件」，粘贴负责人给的安装地址（见下），点安装。
3. 在任意对话里输入 `/desk-setup 地址 钥匙`，看到「写作台配好了」。
4. **完全退出 DeepSeek Harness（⌘Q），再打开。**
5. 点左侧栏「写作台」开一个对话，输入 `/desk-status`，看到「写作台连着。协议版本 …」就成了。

## 负责人要准备什么

- **安装地址**：`git+https://github.com/TangVarie/autowriter.git#<提交号>&path:/clients/dsh-plugin-compat-021`，提交号用默认分支上包含这个目录的那次提交的完整 40 位。
- **钥匙**：每位写手用自己那把（和 WorkBuddy 里同一把就行）。

## 不要做的

- **不要和正常版同时装**：两个包同名，后装的会顶掉先装的。
- **不要装到 0.2.2 上**：能装上，但会少 Office 工具、配完要重启，没必要。Apple 芯片的 Mac 和 Windows 一律装正常版。
- **这台 Mac 的 DSH 哪天升到 0.2.2 了**：先在插件页卸掉这个，再装正常版。地址和钥匙存在凭据库里，卸载不会丢。
- **不要用本地文件夹装的那种「改好的包」**：那种做法把钥匙明文写进了包里，所有人共用一把，换钥匙要改文件。

## 维护

这一份是单独维护的，正常版改了不会自动带过来。两道测试防止两边走歪（`test/branch.test.js`）：

- **正常版不许被兼容改动带歪**：正常版的版本要求、模板写法、Office 工具都还在。
- **该一样的地方一样**：入口、浏览器端、图标、文档逐字节相同；`lib/desk.js` 除了两句「配完要重启」以外相同。`lib/plugin.js` 和预设没法逐字比，正常版改了这两个文件，要手工把改动带过来。

服务端那边的对照测试（`tests/test_dsh_plugin_contract.py`）两个包各跑一遍。

```bash
cd clients/dsh-plugin-compat-021
node --test test/*.test.js
```
